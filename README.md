### Описание темы ВКР
#### Формулировка темы
Разработка Web-приложения планировщика макетов квартир
#### Описание
Результатом дипломной работы будет являться WEB-платформа, на которой пользователь сможет с помощью инструментов создавать планировку квартиры, добавлять
и изменять комнаты, дверные проёмы, окна и элементы мебели (шкаф, стол, стул и т.п), всё это пользователь делает с помощью инструментов
рисования и разметки.

Существующий аналог [Remplanner](https://remplanner.ru/planner/) для понимания.
