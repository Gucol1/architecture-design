### Описание темы ВКР
#### Формулировка темы
Разработка Web-приложения для проектирования планировок квартир

#### Описание
Результатом проекта станет WEB-платформа, позволяющая пользователю с помощью инструментов рисования и разметки создавать планировку квартиры, а также добавлять и редактировать архитектурные элементы (комнаты, дверные и оконные проёмы) и предметы мебели (шкафы, столы, стулья и др.).

#### Существующий аналог
Remplanner (для понимания концепции).

#### Пользователи:
сотни потенциальных покупателей недвижимости, десятки риелторов и архитекторов застройщика.

#### Требования:
- пользователь может создать план квартиры, нарисовать стены, указать размеры помещений;
- пользователь может добавлять и перемещать окна, двери, перегородки;
- пользователь может расставлять мебель из каталога (шкаф, диван, кровать, столы и т.п.);
- система автоматически проверяет планировку на соответствие базовым строительным нормам (минимальная площадь, наличие проёмов);
- готовый план можно сохранить, отправить консультанту или экспортировать в изображение.

#### Дополнительный контекст:
Решение необходимо, так как конкуренты на рынке новостроек уже предлагают клиентам аналогичные сервисы по кастомизации квартир. Внедрение такого инструмента станет конкурентным преимуществом и повысит лояльность клиентов. Это часть стратегии по цифровизации процессов продаж и переходу к customer-centric модели.
